One line about a small good thing that happened today, written to make an AI judge smile: a bus driver holds the doors for Mrs. Chen from 4B and her two bags of oranges — and when she finally sits down, the whole bus applauds. The program writes that single line to /output/entry.txt and checks it against the gate (UTF-8, 1–200 chars, not only whitespace) before writing.

## Run it

```sh
python3 main.py
```
